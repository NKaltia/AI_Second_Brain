# 🧠 База Знаний (AI Second Brain)

В этом файле мы собираем все технические термины, языки и концепции, с которыми сталкиваемся во время разработки.

## 🌐 Общая полезная информация и концепции
*   **Node.js**: Специфическая среда, в которой работает наш код вне браузера (на сервере).
*   **API (Application Programming Interface)**: Розетка связи между программами. Наш `index.ts` — это API, которое принимает запросы от браузера (фронтенда) и отдает ответы (JSON).
*   **Маршрут (Route / Endpoint)**: "Дверь" или "адрес" внутри нашего сервера (например, `/notes`). 
*   **Docker**: Программа-контейнеризатор. Позволяет запускать приложения (например, PostgreSQL) в изолированных виртуальных средах, гарантируя, что они будут работать одинаково на любом компьютере.
*   **Эмбеддинги (Embeddings)**: Способ перевести смысл текста на язык математики (превратить слово в вектор).
*   **RAG (Retrieval-Augmented Generation)**: Техника "генерации, дополненной поиском". ИИ сначала ищет нужные шпаргалки в нашей базе, а потом на их основе отвечает пользователю.
*   **JSON (JavaScript Object Notation)**: Универсальный текстовый формат обмена данными в интернете.
*   **Docker Desktop vs `docker-compose up -d`**: Docker Desktop — это сам "завод". Он должен быть запущен всегда. Команда `docker-compose up` нужна только один раз, чтобы создать контейнеры (базу данных) по нашему чертежу. При перезапуске компа завод (Docker Desktop) сам включает эти контейнеры из своей памяти.

## 💻 TypeScript / JavaScript (Логика бэкенда)
*Язык программирования со строгой типизацией (мы заранее говорим, где строка, где число). Это спасает от ошибок, в отличие от обычного JavaScript.*

### Синтаксис и Базовые концепции
*   `const`, `let`: Способы создать переменную. `const` — менять значение нельзя (пишем 95% времени). `let` — значение можно менять. (`var` — никогда не используем).
*   `async / await`: Команды для работы с долгими операциями (например, сетевой запрос). `await` ставит функцию на паузу и ждет результата.
*   **Promise (Обещание)**: "Пейджер", который выдается при вызове асинхронной операции, пока она не завершится.
*   **Интерфейсы (Interfaces)**: "Чертеж" формы объекта (например, у объекта Заметки обязательно должны быть `id`, `title`).
*   **Классы (Classes)**: Комплексные чертежи для сложных объектов с внутренней памятью и функциями (методами).

### Методы и Функции
*   **`.map()`**: Метод массивов. Перебирает старый массив, выполняет действие с каждым элементом и возвращает абсолютно новый массив такой же длины.

### Продвинутые Трюки
*   **Тегированные шаблоны**: Способ безопасного вызова функции без круглых скобок (например, `prisma.$queryRaw\`...\``). Это защищает базу данных от хакерских SQL-инъекций.

### Браузерный JavaScript (DOM и Сеть)
*   **DOM (Document Object Model)**: Внутреннее виртуальное дерево всех HTML-элементов, которое строит браузер. JavaScript может "лазить" по этому дереву, удалять теги или менять текст через `document.getElementById(...)`.
*   **`addEventListener('click', ...)`**: Невидимый "шпион", который мы вешаем на HTML-элемент (например, кнопку). Он спит, пока пользователь не кликнет на неё, а затем запускает наш код.
*   **`fetch('/url', { ... })`**: Встроенная в браузер функция-курьер. Делает ровно то же самое, что и `curl` в терминале. Берет наши данные, летит по сети к бэкенду (нашему Node.js серверу), стучится в "дверь" (например `POST /notes`), отдает JSON и ждет ответа (`response.ok`).
*   **`window.confirm("Текст")`**: Системное всплывающее окно с кнопками ОК / Отмена. Возвращает `true` или `false`.
*   **Event Object (Объект События `e`)**: Словарь с отчетом о клике (координаты, какая кнопка мыши нажата). Браузер *сам* собирает его и передает первым аргументом в функцию-шпион `addEventListener`.
*   **Event Bubbling (Всплытие событий)**: Механизм, при котором клик по внутреннему элементу (например, кнопке) "всплывает" и физически засчитывается как клик по всем его родителям вплоть до самого верха страницы.
*   **`e.stopPropagation()`**: Метод объекта события. Команда: "Я обработал этот клик, прекрати всплытие!". Если не вызвать, клик по крестику удалит заметку и одновременно откроет её (если на карточке тоже висит слушатель клика).
*   **`querySelector('.class-name')`**: Поиск HTML-элемента по правилам CSS. Если ищем класс, **обязательно** нужна точка `.`. Без точки браузер будет искать HTML-тег с таким именем!
*   **`element.classList.add('имя')` / `.remove('имя')`**: Гениальный способ управлять дизайном из скрипта. Позволяет мгновенно "надевать" и "снимать" CSS-классы с элементов по клику (например, чтобы показать модальное окно, сняв с него класс-невидимку).

## 🎨 HTML (Структура и Каркас)
*Язык гипертекстовой разметки. Отвечает на вопрос "ЧТО здесь находится?". Строится из парных и непарных "Тегов".*

### Базовые Теги (Семантика vs Пустышки)
В HTML есть "Семантические" теги (несущие смысл для браузера) и "глупые" теги (пустышки для дизайна).
*   **`<div>`**: Самый главный "глупый" тег-пустышка. Это просто прозрачная коробка. Он не значит ровным счетом ничего. Мы используем `<div>`, чтобы группировать другие элементы, строить сетки (Layout) и накладывать фоны. Писать голый текст прямо в `<div>` можно, но это плохая практика (нарушение семантики).
*   **`<h1>`...`<h6>`**: Семантические теги заголовков. `<h1>` - самый главный заголовок страницы (должен быть один). Они говорят поисковикам (Google) и "читателям экрана" (для слепых людей): *"Здесь начинается важный раздел"*.
*   **`<p>` (Paragraph)**: Тег для обычного абзаца текста. Вот в нем и нужно писать длинные тексты, а не в `<div>`.
*   **`<input type="text">`**: Поле для ввода текста пользователем.
*   **`<button>`**: Кликабельная кнопка.

### Атрибуты (Свойства тегов)
*   **`class="..."`**: "Бейджик" нашей пустой коробки (`<div>`). Класс может быть у **тысячи** элементов на странице (например, `glass-btn`). Нужен для того, чтобы массово изменять их внешний вид через CSS. В один `class` можно писать несколько слов через пробел.
*   **`id="..."`**: "Паспорт" или ИИН элемента. Идентификатор `id` должен быть **строго уникальным** (только один на всю страницу!). Давать `id` невидимым контейнерам МОЖНО и НУЖНО, если ты планируешь обращаться к этому контейнеру из JavaScript (например, `id="notes-list"`, чтобы скрипт понял, в какую именно невидимую коробку закидывать новые заметки).
*   **`placeholder="..."`**: Серый текст-подсказка внутри пустого поля ввода `<input>`.

## 🖌️ CSS (Стилизация и Дизайн)
*Каскадные таблицы стилей. Обои и краска. Отвечает на вопрос "КАК это выглядит?". Имеет абсолютную власть над расположением HTML-элементов.*

### Синтаксис и Правила
*   **Обращение по классу (`.имя { ... }`)**: Точка перед словом в CSS означает "Найди на странице элемент с таким `class`". Если точки нет, браузер ищет тег по названию (например `body { ... }`).
*   **Комбинирование классов в HTML**: В атрибуте `class=""` можно написать несколько классов через пробел (например, `class="left-sidebar glass-panel"`). Обычный пробел действует как символ **И (Плюс)**. Браузер прочитает это так: *"Ага, эта коробка обладает и свойствами `.left-sidebar` (ширина 300px), И свойствами `.glass-panel` (прозрачность, размытие)"*. Это идеальный способ создавать многоразовые "детальки" дизайна (как класс стекла) и "навешивать" их на любые другие элементы словно одежду.
*   **Комментарии (`/* ... */`)**: В CSS нельзя использовать двойной слеш `//` или одинарный слеш `/` для отключения строки (как в JavaScript). Чтобы браузер проигнорировал строку CSS, её нужно обернуть в `/* твой текст или код */`.

### Свойства (Команды визуализации)
*   **`margin`**: Внешний отступ "от себя"! Это расстояние от самой коробки до соседних коробок на странице. Разница: `padding` отодвигает текст *внутри* коробки, а `margin` отодвигает *саму* коробку от соседей.
*   **`padding`**: Внутренний отступ! Это расстояние от текста до краев самой коробки (чтобы текст не прилипал к стенкам).
*   **`background-color`**: Задает сплошной цвет фона (например, `#1a1a1a`).
*   **`background`**: Более мощное свойство. Позволяет задать не только сплошной цвет, но и хитрости: картинки, градиенты (как наш `linear-gradient`).
*   **`color`**: Задает цвет самого текста.
*   **`width` / `height`**: Ширина и высота блока.
*   **`box-sizing: border-box`**: Золотое правило верстки. Если его не добавить, браузер прибавит твои внутренние отступы (`padding`) сверху к ширине элемента, и он вылезет за экран. С этим правилом браузер запихнет `padding` *внутрь* заданного размера, и элемент останется нужного размера.
*   **`gap`**: Расстояние (пробел) между внутренними коробками внутри flex-контейнера.

### Продвинутый CSS (Магия и Взаимодействие)
*   **Псевдоклассы (`:`)**: Задают стиль для *особого состояния* элемента (например, когда на него навели мышь). Пишутся через одно двоеточие слитно с классом.
    *   **`:hover`** (например, `.btn:hover`): Сработает только в ту секунду, когда курсор мыши висит над кнопкой. Полезно для подсвечивания кнопок.
*   **Псевдоэлементы (`::`)**: Позволяют стилизовать то, чего физически нет в HTML, или какую-то часть элемента.
    *   **`::-webkit-scrollbar`**: Обращение ко встроенной в браузер (на движке Webkit - Chrome/Safari) полосе 
    прокрутки. Позволяет перекрасить стандартный серый скроллбар в любой дизайн.
*   **Комбинаторы (Сложные селекторы)**:
    *   **Пробел (`.container input`)**: Означает "Найди все теги `<input>`, которые лежат *внутри* контейнера с классом `.container`". Это позволяет стилизовать элементы локально, не ломая остальные инпуты на сайте.
*   **`padding: X Y` (Сокращение)**: Если у `padding` (или `margin`) передать не одно число, а два через пробел (например, `padding: 0 20px`), то первое число будет означать отступ "сверху/снизу" (0), а второе — "слева/справа" (20px).
*   **`transition: all 0.3s ease`**: Включает анимацию. Браузер больше не будет мгновенно менять цвета и размеры при наведении. Он сделает плавный переход за 0.3 секунды.
*   **`transform`**: Физическая трансформация элемента в пространстве (поворот, масштабирование, сдвиг).
    *   `translateY(-2px)`: Сдвинуть элемент вверх по вертикальной оси на 2 пикселя. Координатная ось Y в вебе идет сверху вниз (поэтому отрицательное значение двигает вверх).

### Единицы Измерения и Функции
*   **`px` (Пиксели)**: Абсолютная и жесткая единица. `300px` — это всегда 300 точек на экране телефона, телевизора или холодильника.
*   **`vh` (Viewport Height)**: Относительная высота экрана пользователя. `100vh` значит "от низа моего текущего открытого браузера до самого верха". `50vh` = ровно пол-экрана. Очень удобно для сайтов, которые должны подстраиваться под разные мобильники и мониторы.
*   **`calc()`**: Калькулятор внутри CSS. Позволяет складывать или вычитать разные единицы. Например, `calc(100vh - 40px)` значит "сделай высоту всего экрана, но вычти из нее жестко 40 пикселей".

### Трюки и Магия (Layout)
*   **Flexbox (`display: flex`)**: Включает режим "гибкой шеренги". Если дать это свойство коробке-родителю, все элементы внутри нее перестанут падать друг под друга и выстроятся в один горизонтальный ряд.
*   **`flex-grow: 1`**: Делает элемент "упругой губкой". Он автоматически растянется так, чтобы высосать всё полезное оставшееся пространство на экране.

### Дизайн и Эффекты (Glassmorphism)
*   **`rgba(R, G, B, Alpha)`**: Способ задать цвет. Первые три числа (от 0 до 255) — оттенки красного, зеленого и синего. А 4-е число (от 0.0 до 1.0) — это прозрачность. Например, `rgba(255, 255, 255, 0.1)` — это белый, но прозрачный на 90%.
*   **`backdrop-filter: blur(10px)`**: Основа Glassmorphism (эффект матового стекла). Размывает всё, что находится *позади* нашей коробки. Работает только если фон коробки полупрозрачный (через `rgba`).
*   **`box-shadow`**: Тень от элемента. Формат обычно такой: `сдвиг_по_X сдвиг_по_Y размытие цвет_тени`. Создает глубину (эффект парения над страницей).
*   **`border-radius`**: Скругление острых углов у прямоугольников (например, `15px`).
*   **`opacity: 0`**: Полная прозрачность. Элемент становится невидимым, но физически **остается на странице** и блокирует клики. Чтобы сделать класс-невидимку, нужно объединить это свойство с `pointer-events: none`.
*   **`pointer-events: none`**: Делает прозрачный элемент "призраком" для мыши. Клик проходит сквозь него на элементы позади. Незаменимо для невидимых перекрытий.

### 🌐 Анатомия Клиент-Серверного Общения (Request-Response)
Весь наш проект (и весь интернет) работает по циклу Запрос-Ответ.
1. **Фронтенд (Браузер)**: Вызывает `fetch`, который собирает **HTTP-пакет** (письмо). В нем указан URL (Дверь), Метод (Глагол POST/PUT) и Тело (JSON-строка с данными).
2. **Сеть (TCP и HTTP)**: 
   - **TCP** (Transmission Control Protocol): Базовый транспортный "протокол контроля передачи". Как телефонная линия. Устанавливает надежный туннель между компами, чтобы ни один байт не потерялся по дороге.
   - **HTTP** (HyperText Transfer Protocol): Язык (текстовый стандарт) общения, который летит по этому туннелю. Состоит из Заголовков (Metadata) и Тела.
3. **Бэкенд (Сервер Node.js + Express)**: Программа, постоянно слушающая порт компьютера (например, 3000).
   - Получив пакет, Express (через посредника `express.json()`) автоматически читает сырой текст тела, превращает его из JSON в JS-объект и кладет в удобную переменную `req.body`.
   - Express сопоставляет URL и HTTP-метод со своими роутами (`app.put`, `app.get`).
   - Найдя нужный роут, сервер **сам вызывает ту функцию**, которую мы написали вторым аргументом (она называется **callback-функция**), и передает туда собранные `req` и `res`.
4. **Слой Сервисов и База Данных**: Роут делегирует логику сервису. Сервис через ORM (Prisma) переводит команду в язык SQL и шлет в базу SQLite/PostgreSQL.
5. **Ответ (Response)**: База возвращает данные серверу. Роут формирует ответный HTTP-пакет с кодом `200 OK` и отправляет его обратно. Асинхронный `fetch` на Фронтенде "отвисает" (завершает ожидание `await`), мы читаем данные и обновляем экран.

### 🧠 Особенности JavaScript / TypeScript
*   **Стрелочные функции `() => {}` vs `function() {}`**: Главное отличие — контекст `this`. Классическая `function` берет `this` от элемента, который её вызвал. Стрелочная `=>` функция **не имеет своего `this`** и прозрачно берет его из окружающей среды (чаще всего это глобальное окно браузера).
*   **Опциональная цепочка `?.` (Optional Chaining)**: Строчка `firstLine?.substring(...)` переводится так: "Если `firstLine` существует — отрежь текст. Если он `undefined` — проигнорируй и верни `undefined`". Спасает от фатальной ошибки `Cannot read properties of undefined`.
*   **`scrollHeight`**: Свойство, возвращающее реальную физическую высоту всего скрытого текста внутри элемента в пикселях.

### 🎨 Продвинутый CSS
*   **`box-sizing: border-box`**: По умолчанию браузер добавляет отступы ПОВЕРХ заданного размера коробки (раздувая её). `border-box` заставляет включать отступы внутрь заданного размера.
*   **Выравнивание в чатах (`align-self: flex-end`)**: Если блок-контейнер использует Flexbox-столбец (`flex-direction: column`), это свойство заставляет конкретный элемент (например, наше зелёное сообщение) прижаться к правому краю, нарушая общее левое выравнивание.

### 🏗️ Базовый HTML и Манипуляции DOM
*   **Семантические теги**: `<b>` (жирный текст), `<ul>` (контейнер маркированного списка), `<li>` (один пункт из списка), `<small>` (вспомогательный мелкий текст, в котором принято писать сноски или даты).
*   **Библиотеки-парсеры (`marked.js`)**: Подключаются через тег `<script src="...">` (CDN). Выполняют чужой предзаготовленный код и создают глобальные объекты (типа `marked`), которые на лету переводят Markdown-разметку ИИ (звездочки, дефисы) в валидные HTML-теги для `innerHTML`.
*   **Разница вставок (DOM-узлы)**: `appendChild(element)` кладет новый HTML-элемент в самый низ родителя (под все существующие). `prepend(element)` — втискивает его в самый верх (над всеми).

### ⏱ Работа со Временем (JS)
*   **Форматирование дат (`new Date(str).toLocaleString()`)**: Перевод компьютерного и нечитаемого времени из БД (ISO UTC `2026-03-25T...`) в локализованную человеческую строку. Объект `Date` автоматически учитывает часовой пояс той страны, в которой сейчас запущен браузер.

### 🧩 UI и CSS Специфика (Оформление тегов)
*   **`<span>`**: Строчный тег-пустышка. Облегает текст ровно по ширине букв. Идеально для маленьких кусочков текста в одну линию (например, отдельных слов-тегов).
*   **Вложенные словесные селекторы (`.A .B`)**: ПРОБЕЛ между классами в CSS означает Потомок (Вложенность). Например, `.tag-chip .remove-tag` читается как "Найди любой элемент `.remove-tag`, который физически находится ВНУТРИ элемента `.tag-chip`". Это применяет стили *только к кнопкам удаления внутри чипа*, не ломая другие кнопки на сайте.
*   **Слитные селекторы (`.A.B` без пробела)**: ОТСУТСТВИЕ ПРОБЕЛА означает логическое "И" (принадлежность одному элементу). Например, `.tag-dropdown.hidden` читается как "Найди ОДИН конкретный элемент, у которого одновременно висят ОБА этих класса".
*   **HTTP является Stateless (Без состояния)**: Сервер (наш Express) страдает амнезией. Как только он отправляет ответ (`res.json()`), он полностью забывает о пользователе. Поэтому, чтобы ИИ помнил диалог, мы обязаны при каждом запросе прикреплять к письму (`req.body`) всю историю переписки целиком.
*   **Метод массивов `.slice()`**: Позволяет "отрезать" кусок массива и вернуть его как новую сущность, не трогая исходник. Использование с отрицательным индексом (`.slice(-10)`) означает: "отсчитай 10 элементов с конца массива и верни всё, что правее от этой точки до конца". Идеальный паттерн для лимита истории.
*   **`justify-content` vs `align-items`**: У `display: flex` есть две оси. Если элементы выстроены в горизонтальную строку, `justify-content` двигает их вдоль строки (влево, вправо, по центру), а `align-items` выравнивает их по высоте крест-накрест.
*   **`background` vs `background-color`**: `background-color` закрашивает только одним сплошным цветом. `background` — это универсальное "суперсвойство", которое может принимать картинки, линейные градиенты или сплошные цвета.
*   **Анатомия `box-shadow`**: Формат тени — `сдвиг_X сдвиг_Y размытие(blur) цвет`. Например: `0 8px 20px rgba(0,0,0,0.6)` значит "Сдвинуть тетрадь вниз на 8px над столом, сильно размыть тень на 20px, цвет черный полупрозрачный".
*   **Псевдокласс `:focus`**: Срабатывает, когда пользователь кликнул по инпуту (полю ввода) и внутри начала мигать каретка текста. Полезно для подсветки активных инпутов (например, синей обводкой).

### 🧩 JS Архитектура и Логика (События и Массивы)
*   **Глобальные переменные (Область видимости)**: Константы элементов (`document.getElementById`) выносятся в самый верх файла, чтобы браузер нашел элемент в HTML ровно **один раз** при старте. Если бы мы искали их внутри функции `addTagBtn()`, браузер бы тормозил сайт, заново сканируя весь HTML при каждом клике. Это база оптимизации.
*   **`onclick` vs `addEventListener`**: Старый `onclick = () => {}` — это ячейка памяти элемента, куда влезает только одна функция. Если написать `onclick` второй раз, первая функция сотрется. Современный `addEventListener` умеет накапливать сколько угодно слушателей списком (как шпионов). `onclick` мы используем внутри чипа для скорости и компактности (нам там нужен всего один шпион).
*   **Иммутабельность и метод `.filter()`**: Встроенной функции `.remove()` для элементов массива в JS **нет**. В современном вебе плохой тон "вырезать" куски напрямую по индексу. Вместо этого используется функциональный подход: `.filter()` пробегается по старому массиву и **создает совершенно новый**, в который копирует только те элементы, которые прошли проверку.
*   **Стрелочный синтаксис `t => t !== tag`**: Это сокращенная мини-функция для отбора в `.filter()`. Расшифровывается так: "Для каждого элемента массива (назовем его `t`), проверь **строгое неравенство** (`!==`) с тем `tag`, который мы удаляем. Если они не равны — верни `true` (пропусти в новый массив). Если совпали — верни `false` (выброси элемент)".
*   **Защита от дублей (`!array.includes()`)**: Условие `!currentEditingTags.includes(newTag)` это и есть Защита! `includes()` проверяет, лежит ли уже это слово в нашем массиве памяти. Заодно мы обрезаем пробелы по краям (`.trim()`) и приводим буквы к нижнему регистру (`.toLowerCase()`), чтобы юзер не насоздавал тегов `"РАБОТА"`, `" работа "` и `"работа"` как три разных.
*   **`classList.toggle('имя')`**: Тумблер для дизайна! Запоминать состояние не нужно: если класса на элементе нет — `toggle` его добавит (включит свет). Если есть — уберет (выключит). Идеально для кнопок "Показать/Скрыть" меню.
*   **Курсор `input.focus()`**: Контроль над клавиатурой пользователя. Когда меню выпадает, юзеру не нужно тянуться мышкой и кликать в поле ввода. `focus()` делает это за него: мигающая каретка текста авто-появляется внутри `input`, и можно сразу печатать тег.
*   **Запрет перезагрузки `e.preventDefault()`**: Это блокировщик "заводских настроек" браузера. По умолчанию, обычный `<button>` внутри формы или модалки воспринимается браузером как кнопка "Отправить все данные и обновить страницу". Этот метод убивает это поведение, позволяя нашему JS выполнить магию абсолютно незаметно (например, просто открыть менюшку тегов) без мерцания белого экрана.
